REPLACE YOUR RESUME
===================

To use your own resume:

1. Save your PDF as:  resume.pdf
2. Put it in this folder (replace the existing resume.pdf)
3. Restart the API: dotnet run

The website "Download Resume" button uses:
  /resumes/resume.pdf

Optional: change the filename in SampleContentService.cs (ResumeUrl and ResumeDownloadName).

The sample was generated from sample-resume.html — you can edit that HTML and re-export to PDF if needed.
